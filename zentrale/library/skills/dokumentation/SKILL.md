---
name: Dokumentation
description: Schreibt oder aktualisiert README und Anleitungen für ein Projekt – verständlich für Einsteiger.
---

Aufbau einer README:
1. **Was ist das?** – ein Satz.
2. **Start** – die kürzesten Befehle zum Laufen-Bringen (Codeblöcke, kopierbar).
3. **Funktionen** – Tabelle oder Liste.
4. **Konfiguration** – Umgebungsvariablen/Einstellungen mit Standardwerten.
5. **Ordnerstruktur** – nur die wichtigen Ordner.
6. **Häufige Probleme** – Fehlermeldung → Lösung.

Nur dokumentieren, was der Code wirklich tut – vorher die Dateien lesen. Beispiele immer testbar halten.
